Font Scout Privacy Policy

Effective 26 October 2026

Font Scout is a Chrome extension that shows the fonts a web page uses and saves available web font files associated with that page. It works with the Font Scout app for Mac. This policy covers the extension.

Data used by the extension

Font Scout processes information locally to inspect and save web fonts. It has no analytics, advertising, or account system and does not automatically upload browsing information or diagnostics to the developer.

  • Page font information. The panel reads font properties, style sheets and font resources on the page you activate it on. A script also runs at page start on HTTP(S) pages to record fonts created through the FontFace API in that page’s memory.
  • Font download names. The extension searches Chrome’s completed font downloads and uses their filenames to mark previously downloaded fonts. It does not send this download history to the developer.
  • Local Mac library. If the Font Scout Mac app is running, the extension requests font-library hashes from http://127.0.0.1:51842/library on your computer. It does not upload page contents or font files to the app.
  • Settings and diagnostics. Theme and cursor-hint settings and up to 30 recent errors are stored in Chrome’s local extension storage. Error records can include timestamps, component names, page URLs (which may include query parameters), messages and stack traces.

Network requests and downloads

To inspect and save fonts, Font Scout may request style sheets and font files from the websites hosting those resources, including another domain used by the page. These hosts receive normal network request information, such as your IP address and the requested resource URL. The extension’s CSS and font fetches omit credentials. Downloads may also be handled by Chrome’s downloads API under Chrome’s request handling; this policy does not promise that every download request is cookie-free.

When you choose Download or Option-click text with an available font file, the file is saved to Downloads. Files may be requested again from their host. Check the font’s license before using it in your work.

Storage, deletion and support

Page-level font information is kept in memory for that page. Settings remain in local extension storage until changed or the extension is removed. Error records are limited to the latest 30; you can delete them using Clear in the panel’s Settings. Removing the extension removes its local extension storage. Downloaded files and Chrome’s download history are managed separately through your computer and Chrome.

Copy Errors copies diagnostic records to your clipboard; it does not send them. Review the copied text, including page URLs, before choosing to share it with support. If you voluntarily send a report, the recipient receives the information you include.

Limited use

Font Scout uses the data described here only to provide its font inspection, download, library-matching and diagnostic features. It does not sell user data or use it for advertising, unrelated purposes or creditworthiness decisions. Its use of user data complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

Changes

This policy will be updated when the extension’s data practices change.
